# Milestones.

## Milestone 0: Modelizar incialmente el dominio.

Este hito desarrollará el modelo inicial que será el correspondiente a la HU001. Para ello se usará DDD como metodología, determinando los datos y relaciones necesarios para satisfacer la situación descrita en la citada historia de usuario. Se considerará valido cuando todos los datos de la historia de la HU001 y sus respectivas relaciones den lugar a poder implementar la lógica de negocio. 

## Milestone 1: Implementar la lógica de negocio.

Este hito usará el modelado del hito anterior para, a partir de el, implmentar la lógica de negocio para dar una solución al problema descrito en la HU001. Se considera superado cuando se tenga una solución a lo mencionado que satisfaga lass necesidades del usuario correctamente.
