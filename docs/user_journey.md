# USER JOURNEY

Descripción del uso de la aplicación por parte de un usuario desde que decide que va a usar la aplicación hasta que deja de usarla.

Angel es una gran aficonado a la montaña, el vive en Andujar y todas las semanas le gusta subir a Sierra Magina, que aunque le pilla un poco lejos, tiene su lugar favorito, Peña Jaén.

Para realizar sus ascensiones, todos los Viernes usa la aplicación para decidir si irá el Sabado o el Domingo. Al entrar se han estado obteniendo durante la última semana los datos del tiempo en la zona de Sierra Magina y calculando cada uno de los dias la temperatura esperada en la cumbre, la sensación termica esperada y una estimación del estado de la nieve a partir de fotos satelite,temperaturas y precipitaciones recientes.

Leyendo los datos de la aplicación, como este finde le apetecía realizar la ruta del canuto de Peña Jaén, escoge el Domingo, pues es el dia que tendrá las temperaturas más bajas y en base a los datos de los últimos dias, la nieve estará dura y apta para subir usando piolets y crampones.

Así en poco minutos, con un simple vistazo a todos los datos que automáticamente se muestran Angel ha podido decidir adecuadamente y pasa un dia seguro y divertido enla montaña.
