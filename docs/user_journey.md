# User journey

Descripción del uso de la aplicación por parte de un usuario desde que decide que va a usar la aplicación hasta que deja de usarla.

Una persona accede a la aplicación si desea hacer la ruta de peña Jaén, la aplicación obtiene datos públicos de manera automática y proporciona al usuario toda la información importante a la hora de planear una ruta, así como una recomendación de fecha y ruta.
